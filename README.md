#  **E-Commerce Sales Analysis**

## 📌  About The Project 

This project focuses on analyzing E-Commerce Superstore Sales Data using Python.

The main purpose of this project is to explore the dataset and find useful insights about sales, profit, categories, sub-categories, and customer segments.

Different data visualization techniques are used to make the analysis easy to understand.

## 🎯 Project Objectives
The main objectives of this project are:
- Analyze overall sales performance
- Analyze monthly sales trends
- Analyze monthly profit trends
- Analyze sales by category
- Analyze sales by sub-category
- Analyze profit by category
- Analyze profit by sub-category
- Compare sales and profit across customer segments
- Understand the relationship between sales and profit

## 📂  Dataset 
The project uses an E-Commerce Superstore dataset.

The dataset contains information related to:
- Order Date
- Ship Date
- Sales
- Profit
- Category
- Sub-Category
- Customer Segment
- And other important sales information

## 🔍 Analysis Performed
### 📖 1. Data Exploration

The dataset was explored to understand its structure and information.

The following methods were used:
- head()
- info()
- describe()

This helped in understanding:
- Dataset structure
- Data types
- Statistical information
- Available columns

### 📅 2. Date Conversion

The date columns were converted into datetime format.
This makes it easier to perform time-based analysis.

### ⚙️3. Feature Engineering

New columns were created from the Order Date to perform better analysis.

These include:
- 📆 Order Month
- 📅 Order Year
- 🗓️ Order Day

### 📈 4. Monthly Sales Analysis

Monthly sales were analyzed to understand how sales change over time.
A line chart was used to visualize the monthly sales trend.

### 🛍️ 5. Sales by Category

Sales were analyzed across different product categories.

This helps identify:
- High-performing categories
- Category contribution to total sales

### 📦 6. Sales by Sub-Category

Sales performance was compared between different sub-categories.
A bar chart was used for better comparison.

### 💰 7. Monthly Profit Analysis

Profit trends were analyzed month by month.
This helps understand changes in profit over time.

### 💵 8. Profit by Category

Profit was analyzed across different product categories.
This helps identify which categories are more profitable.

### 📊 9. Profit by Sub-Category

Profit generated by different sub-categories was compared.

This analysis helps identify:
- Highly profitable sub-categories
- Low-performing sub-categories

### 👥 10. Customer Segment Analysis

Sales and profit were compared across different customer segments.

This helps understand:
- Which customer segment generates higher sales
- Which customer segment generates higher profit

## 📊 Visualizations
The following visualizations were created in this project:

- 📈 Line Charts - For monthly sales and profit trends
- 📊 Bar Charts – For category and sub-category comparisons
- 🥧 Pie Charts – For category-wise contribution

These charts help convert raw data into easy-to-understand insights.
